# Forums and threads: server contract for clients

This contract now lives in the published documentation, which is generated from the same schemas
the server validates against:

- [Threads and forums](../fluxer_docs/src/content/docs/topics/threads-and-forums.md), the lifecycle,
  access rules, forum settings, and gateway events.
- [Channels](../fluxer_docs/src/content/docs/http-api/channels.mdx), the channel object, the thread
  metadata, thread member, and starter message preview objects, and every per-thread route.
- [Guild channels](../fluxer_docs/src/content/docs/http-api/guild-channels.mdx), the guild-wide
  active threads route clients use on guild select.
- [Gateway events](../fluxer_docs/src/content/docs/gateway/events.md), the four thread events and
  who receives them.

Keep changes in the published docs; this file is a pointer so older links do not dead-end.
