# NNNN. Short title in the imperative

## Status

Proposed | Accepted | Superseded by [NNNN](NNNN-other.md) | Deprecated

Date: YYYY-MM-DD

## Context

What forced the decision. Constraints, the state of things, what was tried.
Written so it still makes sense to someone who was not there - the value of an
ADR is almost entirely in this section.

## Decision

What was decided, in the active voice. "We will..." Be specific enough that a
reader can tell whether a given implementation conforms.

## Consequences

What this makes easy, what it makes hard, and what it costs. Include the
consequences you are unhappy about - an ADR with only upsides is a advert, and
nobody trusts it enough to revisit it later.

## Alternatives considered

Each with one line on why it lost. This is what stops the same argument being
had again in six months.
